Features You want to try it out here is a link https://8051987-eng.github.io/CALM/ • text boxes to put you information in• Check boxes for agreeing on what the website will do • Flexible page switching go from Input page to checkbox page. How It Works the website uses Html css and js html for the text boxes checkboxes header and text while css for the color and font size js for what the textboxes and checkboxes do also buttons.
